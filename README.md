# PRRSV 통합 분석 대시보드 (경기 이천·여주)

## 구성 파일 (모두 저장소 루트에 함께 두기)
- `index.html` — 탭 허브(첫 화면)
- `dash_routes.html` — ① 추정 유입경로 (2층 AHP)
- `dash_tree.html` — ② 계통수 검증
- `dash_map.html` — ③ 계통 × 지리 + 설문
- `dash_subtree.html` — ④ 계통별 하위 계통수
- `dash_network.html` — ⑤ 차량동선 전파망 (합성 데모)

지도/계통수는 인터넷 연결 시 표시됩니다.

## 업데이트(GitHub): 변경/추가된 파일을 같은 저장소에 Upload→Commit 하면 같은 주소가 갱신됩니다.
